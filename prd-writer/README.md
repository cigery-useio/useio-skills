# PRD Writer — UseIO 技能

> 为国内 2B 企业级和 2C 消费级开发量身打造的产品需求文档（PRD）撰写技能。内置 6 套差异化模板，通过结构化访谈、智能模板选择、质量校验闭环，产出实施级规格文档。

## ✨ 核心特性

- **🎯 结构化访谈**：写 PRD 前必做需求澄清，通过 1-3 轮结构化提问补齐关键信息，拒绝"拿到需求就写"
- **📋 多模板体系**：内置 6 套差异化模板（B2B SaaS / 内部管理系统 / 数据平台 / API 平台 / 2C 移动端 / 2C Web 产品），按项目类型智能选择
- **🔒 B2B 企业级专项**：覆盖等保合规、数据安全法、多租户隔离、RBAC 权限、审计日志、私有化部署、审批流引擎、数据脱敏、国密算法、信创兼容
- **📱 2C 消费级专项**：覆盖用户增长漏斗、推送策略、分享裂变、A/B 测试、内容审核、SEO、前端性能优化、商品与交易系统
- **✅ 质量校验闭环**：62 项检查清单（通用必检 + 6 类专项检查），确保每个需求可测试、可度量
- **🔄 全链路闭环**：需求澄清 → 分析界定 → 模板撰写 → 质量校验 → 交付协作，5 个 Phase 环环相扣
- **🇨🇳 中文优先**：面向国内开发团队，术语保留英文原词（RBAC、SaaS、API、DAU），符合开发者习惯

## 📋 模板体系

### B2B SaaS 模板

适用于多租户、订阅制、面向企业客户的产品。

**核心专项章节**：多租户架构与数据隔离、RBAC 权限模型、计费与订阅、安全与合规要求、部署方案（SaaS/私有化/混合云）

**适用场景**：企业协同办公、CRM、ERP SaaS、项目管理工具

### 内部管理系统模板

适用于组织内部使用的管理系统。

**核心专项章节**：组织架构与权限模型、审批流引擎、报表与数据分析、系统集成方案、部署方案（内网/SSO）

**适用场景**：采购审批、OA 系统、HR 系统、财务报销

### 数据平台模板

适用于数据采集、存储、分析、服务的平台型项目。

**核心专项章节**：数据采集与接入、数据存储与建模、数据治理、数据服务层、数据安全与脱敏

**适用场景**：电商数据分析、BI 平台、数据中台、实时大屏

### API 平台模板

适用于对外开放接口、开发者门户、第三方集成的平台。

**核心专项章节**：API 设计规范、认证与授权、限流与配额、版本管理与生命周期、开发者门户

**适用场景**：开放平台、物流 API、支付 API、IoT 数据接口

## 🔄 工作流

```
Phase 0：需求澄清
  │  结构化访谈（1-3 轮 ask_followup_question）
  │  按需：recall_memory / query_knowledge_base / extract_document
  ▼
Phase 1：需求分析与范围界定
  │  竞品分析（web_search）/ 需求拆解 / 范围界定 / 复杂度评估
  │  按需：plan（复杂项目结构规划）
  ▼
Phase 2：模板选择与 PRD 撰写
  │  读取模板（read_skill_file）/ 逐章节填充 / 质量自检
  │  输出文档（write_file）
  ▼
Phase 3：质量校验
  │  读取校验清单（read_skill_file）/ 逐项检查 / 修正不合格项
  ▼
Phase 4：交付与协作
     自动打开文档（open_target）/ 角色专属摘要 / 后续建议
```

## ✅ 质量标准

### 需求描述质量

禁止模糊词汇，必须量化：

```diff
# 模糊（错误）
- 搜索功能要快速返回相关结果

# 具体（正确）
+ 搜索功能在 10 万条数据量下，95% 请求响应时间 ≤ 200ms
```

### 验收标准质量

每个功能需求必须有可测试的验收标准：

```diff
# 模糊（错误）
- 支持多租户

# 可测试（正确）
+ 租户 A 的用户无法看到租户 B 的任何数据（包括列表、详情、报表）
+ 租户管理员只能管理本租户的用户和角色
+ 跨租户数据隔离在数据库层面通过 tenant_id 字段实现
```

### B2B 专项质量要求

| 维度 | 要求 |
|------|------|
| 等保合规 | 明确等保级别（2 级/3 级），列出安全要求 |
| 数据安全法 | 个人信息全生命周期管理 |
| 多租户隔离 | 明确隔离级别，数据泄露防护方案 |
| RBAC 权限 | 角色-权限矩阵，数据权限与功能权限分离 |
| 审计日志 | 记录范围、保留期限、查询权限 |
| 私有化部署 | 部署架构、数据迁移、升级方案 |
| 审批流 | 流程定义、回退/会签/委托、通知机制 |
| 数据脱敏 | 脱敏规则、字段清单、权限控制 |
| 国密算法 | SM2/SM3/SM4 适用场景 |
| 信创兼容 | 国产 OS/数据库/中间件适配 |
